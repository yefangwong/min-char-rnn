# 🔄 RNN vs. LSTM: 結構與物理幻化的差異對比

這份文件記錄了從 Vanilla RNN (SimpleRNN) 進化到 LSTM (Long Short-Term Memory) 的技術跨越，重點在於資訊如何在 JVM 記憶體中被承載。

## 1. 記憶體軌道的擴張 (The Memory Tracks)

| 特性 | SimpleRNN.java | LSTM.java |
| :--- | :--- | :--- |
| **記憶軌道** | 單一軌道：`ht` (Hidden State) | 雙軌道：`ht` (短期) + `Ct` (長期/Cell State) |
| **物理本質** | 每一步都經過非線性擠壓 (`tanh`)，資訊易流失。 | `Ct` 採用線性加法，誤差訊號可無損回傳。 |
| **背誦能力** | 約 5~10 個字後開始胡言亂語。 | 可輕鬆記住 50 個字以上的長難句（如聖經金句）。 |

---

## 2. 閘門邏輯：指標的「分流器」 (Gating Mechanism)

在 `SimpleRNN` 中，所有輸入都是全量進入。但在 `LSTM` 中，我們引入了「閘門」來精確控制指標流：

1.  **遺忘閘 (Forget Gate)**：
    *   **作用**：決定舊的 `Ct` 裡哪些數值指標該被清空。
    *   **物理效應**：防止無用的歷史資訊干擾當下的判斷。
2.  **輸入閘 (Input Gate)**：
    *   **作用**：決定當前的新資訊有多少值得被「幻化」進 `Ct`。
    *   **物理效應**：過濾雜訊，只存儲強關聯特徵。
3.  **輸出閘 (Output Gate)**：
    *   **作用**：從長期記憶 `Ct` 中「過濾」出當前要展現的 `ht`。
    *   **物理效應**：將深層記憶轉化為表層輸出。

---

## 3. 權重矩陣的物理佈局優化 (Layout Optimization)

為了對應 **Exp-001 (記憶體佈局對比)**，我們在實作上做了重大改變：

*   **SimpleRNN**：權重分散，`wxh`, `whh` 等各自獨立。
*   **LSTM**：採取 **「大塊切割 (Big Chunk)」**。
    *   定義 `4 * HIDDEN_SIZE` 的高度。
    *   一次矩陣乘法產出四個閘門的原始數據（gateRaw）。
    *   **優勢**：利用 **CPU 空間局部性**，減少 JVM 指標跳轉導致的 Cache Miss。

---

## 4. 學習與收斂：指標的「慣性」

*   **SimpleRNN**：梯度消失嚴重，模型容易陷入「局部最優解」，或者直接無法學習長距離依賴。
*   **LSTM**：
    *   透過 **梯度裁剪 (Clip Gradients)** 壓制數值爆炸。
    *   透過 **Adagrad** 為每個權重指標提供獨立的「學習步伐」。
    *   **結果**：收斂速度比 RNN 快出數倍，且生成的文字具備長程邏輯一致性。

---

## 5. 總結：給開發者的觀察點
當你看到 LSTM 完美背出「向著標竿直跑，要得 神...」時，這代表 **`Ct` 軌道上的數值指標成功跨越了 40 個時間步的連鎖運算而沒有崩潰**。這是 SimpleRNN 永遠無法觸及的物理極限。
